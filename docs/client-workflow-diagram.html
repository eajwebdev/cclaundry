Customer

1

Open booking page

Customer views available branches, services, pickup windows, delivery preference, and payment options.

2

Submit pickup request

Customer enters name, mobile number, address, service items, quantity, pickup date/time, optional delivery details, and notes.

3

Receive booking reference

The system creates a booking reference such as PU-YYMMDD-0001. Customer can save it for tracking.

4

Track every stage

Customer sees collection, washing, drying, folding or steaming, and ready status. Rider location appears during active pickup or delivery.

5

Receive laundry

If delivery was selected, the rider returns the laundry. If branch pickup was selected, the customer claims it at the branch.

Admin / Staff

1

Review new booking

Admin sees the online pickup request in the Pickup Bookings screen with customer details, branch, service lines, address, and schedule.

2

Confirm or cancel request

Admin confirms the pickup, contacts the customer when needed, or cancels with a reason if the request cannot proceed.

3

Assign rider

Admin assigns a rider to the request. A rider may also self-claim an unassigned booking from the rider console.

4

Load bag in POS

Cashier taps Load tag # beside Walk-in / Delivery. Search by tag, booking, or customer, or choose from the 9 oldest waiting bags.

5

Create & process job order

Verify weight, services, price, and payment in the same POS used for walk-ins. Create the job order; track washing, drying, and folding or steaming.

6

Mark ready & release

Mark ready for pickup or delivery. Staff releases counter orders; rider completion releases eligible delivery orders.

Driver / Rider

1

View available runs

Rider sees own runs plus unassigned branch bookings. Map view shows pickup and delivery locations when coordinates are available.

2

Claim or accept assigned run

Rider confirms the booking from the mobile console. The booking becomes assigned and status moves to confirmed.

3

Navigate to customer

Rider uses routing and shares location pings. Admin and customer tracking can show the rider's live position.

4

Collect & tag bag

Rider records a bag tag and any payment at collection. A tag already used today, or still on an active bag, cannot be reused.

5

Return to branch

Rider hands the tagged bag to staff. Its booking joins the POS waiting tag list until a job order is created.

6

Deliver finished laundry

When the job order is ready for delivery, rider brings it to the customer and marks the run completed.

Important Handoffs

Customer -> Admin Online booking creates a pending pickup request with a reference number.
Admin -> Driver Booking is confirmed and assigned, or a rider claims it from the available list.
Driver -> Admin Rider returns a tagged bag; cashier finds it in POS and creates the job order.
Admin/Driver -> Customer Customer tracks washing, drying, finishing, and ready status before delivery or branch pickup.

Exception Paths

  • Customer can cancel while the booking is still pending or confirmed.
  • Admin can cancel a booking or job order when it cannot proceed.
  • Driver can release a run back to the branch list before collection.
  • Driver can cancel from the road with a required reason if pickup fails.
  • Cancelled requests leave the active flow; completed or cancelled records remain available for reporting.

System Records Created

  • Customer profile or matched existing customer record.
  • Pickup request with booking reference, service items, and collection bag tag.
  • Rider assignment and location pings when sharing is active.
  • Job order, job items, payments, customer ledger, and inventory movements.
  • Activity logs and optional SMS notifications for status changes.
